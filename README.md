# 2ms-github-action 

**2ms-github-action** is a tool designed to run and compare different versions of the 2ms Project. It allows you to execute 2ms using two different versions (new and old), as well as compare the results generated by each version.  

## Installation  

### Clone the repository:  

```sh
git clone https://github.com/SCS-Micro-Engines/2msRunner.git
```  

### Compile from source:  

```sh
cd 2msRunner
go build -o 2msRunner
./2msRunner
```  

## Setup  

Before running the tool, you need to set a GitHub token in your environment variables:  

- **Windows (PowerShell)**:  
  ```powershell
  $env:GITHUB_TOKEN="your_github_token"
  ```  

- **Linux/macOS (bash/zsh)**:  
  ```bash
  export GITHUB_TOKEN="your_github_token"
  ```  

Additionally, ensure that you have the executable files for both the **old** and **new** versions of 2ms before running the comparison.  

## Command Line Help  

⚠ **Warning:** You must specify both the `--old` and `--new` flags when running 2msRunner to compare different versions properly.


```
Tool to run and compare 2ms project versions  

Usage:  
  2msRunner [command]  

Examples:  

# Run 2ms with both new and old executables  
2msRunner --old /path/to/old_2ms --new /path/to/new_2ms  

# Load repositories from a custom file  
2msRunner --custom-repo --old /path/to/old_2ms.exe --new /path/to/new_2ms.exe  

# Execute result comparison  
2msRunner --old /path/to/old_2ms.exe --new /path/to/new_2ms.exe --compare-results  

Available Commands:  
  clean       Clean up files and directories  
  help        Help about any command  

Flags:  
      --compare-results   Create report to analyse results that appears only in one Exe
      --custom-repo       Load repositories from custom fil 
  -h, --help              help for 2msRunner  
      --new string        New 2ms Exe  
      --old string        Old 2ms Exe  

Use "2msRunner [command] --help" for more information about a command.  
```

ℹ **Note:** When using the `--custom-repo` flag, the tool will load repositories from a predefined path within the repository: `./repos/customRepos.json`. The file should be structured as follows:

```json
{
    "projects": [
        "https://github.com/gitleaks/gitleaks.git",
        "https://github.com/checkmarx/2ms.git"
    ]
}
```

📊 Result Storage: The results of the comparison will be written to a local CSV file located at: ./repos/repos.csv.


If you do not use the --custom-repo flag, the tool will make an API call to GitHub and search for repositories with more than 1000 stars.
